$username = $_POST['username'];
$password = $_POST['password'];

$query = "select * from users where username='$username' and password='$password'";

if(mysqli_num_rows($result) > 0) {
echo "Login Berhasil";

echo "Login Gagal";

yang ini mudah di retas!!!

menyerang menggunakan - Bypass Universal Login
Masukan :
username : bebas
password : ' OR '1'='1

dan itu mudah di jebol kalo database nya tidak di perbaiki!!

cara mencegah agar database tidak di retas/bobol, Gunakan Prepared Statement!
Ubah login.php menjadi seperti ini:

<?php
$conn = mysqli_connect("localhost","userdb","admin","sqldb");

$username = $_POST['username'];
$password = $_POST['password'];

$stmt = $conn->prepare("select * from users where username=? and password=?");
$stmt->bind_param("ss",$username,$password);
$stmt->execute();
$result = $stmt->get_result();

if($result->num_rows > 0) {
   echo "Login Berhasil";
} else {
   echo "Login Gagal";
}
?>
